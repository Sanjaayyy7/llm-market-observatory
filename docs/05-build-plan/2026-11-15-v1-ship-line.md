# LLM Market Observatory v1.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the v1.0 line (G0–G7 plus descriptive G8–G9): a governed SCD2 history of first-party LLM list prices rebuilt from LiteLLM git, the headline "Y% of top-tier models cut within 365 days", an Epoch ground-truth check, and a static dashboard on GitHub Pages.

**Architecture:** Python fetchers (`ingest/`) do all network I/O and write Parquet to `data/raw/`. dbt-duckdb builds staging → intermediate → marts with no network access. `analysis/` reads the marts and writes `exports/`. An Observable Framework site renders the exports. CI runs everything against small committed fixture Parquet.

**Tech Stack:** Python 3.12 + uv, DuckDB, dbt-core + dbt-duckdb, pandas, lifelines, statsmodels, pytest, ruff, Observable Framework (Node 20), GitHub Actions + Pages.

**Spec:** `docs/03-spec/design.md` v1.2 and `docs/03-spec/PRD.md` v1.2. Spike numbers: `docs/04-feasibility-spike/feasibility-spike.md`.

## Global Constraints

- Pins: Python 3.12; `duckdb>=1.5,<2`; `dbt-core~=1.12.6`; `dbt-duckdb~=1.11.1`; `uv.lock` committed. No dlt, Airflow, Dagster, Elementary or dbt-metricflow (G10 deferred).
- Site: Observable Framework on Node 20 LTS. Ship Parquet, never `.duckdb`. Pin the npm version exactly, to a release at least two weeks old.
- dbt never calls the network. Every fetcher writes `data/raw/<source>/` Parquet, appends one row to `data/raw/_freshness.parquet`, and is idempotent per run date (re-run overwrites that run's partition).
- CI has no network access to data sources and runs no LLM calls. It uses the committed fixtures in `tests/fixtures/raw/` via dbt var `raw_root`.
- Price = first-party, standard tier, `blended = (3·in + 1·out)/4 × 1e6` USD per 1M tokens. Vertex, Bedrock, Azure and other clouds are not first-party.
- Cut = blended drop of ≥10% (`pct <= -0.10`) vs the previous version of the same canonical model. Correction = reverted within 14 days, or within 7 days of listing.
- Top-tier = Arena `text` / `overall` rank percentile ≤25%, with rank recomputed by rating within the snapshot, on the first snapshot within 60 days after listing.
- Canonical ID rule = design §6 (v1.2). Mode filter = design §5 (v1.2).
- Kill criteria = design §18. A tripped criterion stops the task. Report it; never work around it.
- **Hard stops (ask the user):** G2 crosswalk approval; Epoch benchmark scores unobtainable at G1; G5 failing after one diagnosis pass; before `gh repo create` / first push.
- Branch per gate: `gN-<slug>`. Fast-forward to `main` when the gate passes. `main` is always shippable. Commits use `<type>: <description>`.
- Every merged gate adds `docs/drills/<slice>.md` with three questions and no answers: its grain, one test it relies on, one failure mode.
- Every builder call adds a row to `docs/DECISIONS.md`: `choice | rejected alternative | why | E-ID`.
- Update `docs/STATUS.md` at the end of every session.
- The GateGuard hook asks for facts before the first Bash and the first Write/Edit per file. State them and retry.

## Review Focus

1. **Null or changing `mode`.** Every key on 2023-09-06 has null mode. A key must not look delisted or relisted because its mode was filled in later. → Task 4 test `test_null_mode_key_not_delisted`.
2. **Zero or null prices.** Free previews and missing output costs: a move to or from 0 or null is never a cut, and those rows are excluded from cut detection. → Task 6 unit tests `zero_to_price_not_cut`, `price_to_zero_not_cut`.
3. **Float noise in per-token costs** (`1.5e-07` vs `1.4999999e-07`) must not create a price version. Compare per-1M prices rounded to 6 decimals. → Task 4 test `test_float_noise_no_new_version`.
4. **Arena renames and variants.** The 2026-10-20 display-name rename, "(High)" and "-thinking" all map to one canonical model, ranked at the best variant in the snapshot. → Task 5 tests `test_canon_collapses_variants`, `test_rank_is_best_variant`.
5. **Interrupted or rewritten replay.** A crash mid-run, or a LiteLLM force-push that leaves the state sha out of history, must still produce the same hash as a clean full run. → Task 2 tests `test_partial_run_recovers`, `test_rewritten_history_full_replay`.
